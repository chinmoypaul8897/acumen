* **the day's own master** -- 2026-08-17 is in the future and no pre-open has fetched its dump.

  gate moves that discovery from 09:14 to the day before.

  this machine. No live morning has ever been run here, so nothing has ever cached it. The
  refusal names the file, the reason and the remedy.
* **the test message** -- it has not been sent, and the gate will not certify a chat it has
  never reached. This one refuses on every first run by design.

The four that pass are the four that can be certified today, and each is a real measurement:
both `.env` keys exist (their VALUES were not read into anything that outlives the call, and no
value appears anywhere in the report); the shipped universe filter really screens 204 and names
the six; the fence really refuses a networked corporate-action refresh for both roots; and the
no-order tripwire suite was RUN -- 14 passed in 24.96s -- rather than cited.

**This is what the gate is for.** A week started on this machine, today, without the gate would
have died at 08:45 on the calendar and again at 09:14 on the master, and would have discovered
on the first real signal whether the trader's phone was reachable at all.
